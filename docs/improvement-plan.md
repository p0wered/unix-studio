### Исправление: артефакты в градиентах

В фазе 2 свечения были пережаты в WebP q80 (~10 КБ): в тёмной части градиента появились квадраты 16×16. Причина — в исходнике был мелкий шум (остаток альфа-канала старого PNG), который служил дизерингом; кодек его сгладил блоками. Теперь: исходник слегка сглажен (шум 1–3 уровня яркости, глазу не виден), основной формат — AVIF 8-bit 4:4:4 (10–12 КБ), фолбэк — WebP q95 (~22 КБ), через `image-set()` в CSS. 10-битный AVIF не подошёл: Chrome рисует его с ошибкой округления (зелёный оттенок и квадраты по границам тайлов).

### Свечения теперь прозрачные

Фоны со свечением (Hero, бегущая строка, картинка на About) были «запечены» поверх `#1a1a1a`, поэтому после смены `--content-dark` на `#131313` их тёмные области разошлись с остальной страницей. Теперь это PNG-исходники с альфа-каналом (как в оригинальном дизайне), линии удалены, сглаживание в premultiplied-пространстве; AVIF 8-bit с альфой (18 и 16 КБ) + WebP-фолбэк. ### Исправление: фоны на ultrawide (3440×1440)

Ошибки из исходного CSS, видные только шире ~1920px:

- секция с бегущей строкой: фон `cover` был центрирован по вертикали (`background-position: 0`) — когда картинка масштабируется по ширине, у свечения обрезался мягкий верхний край. Теперь фон прижат к верху (`0 0`); на обычных экранах ничего не меняется (там картинка масштабируется по высоте).
- блок с фото на About: фон натурального размера (1920px) повторялся — шов и второе свечение справа. Теперь `background-size: max(1920px, 100%) auto` без повтора: до 1920px как было, шире — растягивается.

В визуальные тесты добавлена ширина `ultrawide` 3440×1440.

### Визуальные тесты стали строже

Порог сравнения пикселей был по умолчанию 0.2 — под него проходила смена `#1a1a1a` → `#131313`. Теперь `threshold: 0.01`: тонкие изменения цвета тоже ловятся. Из-за этого всплыл шум растеризации картинок (Chrome сначала рисует их упрощённой фильтрацией): перед снимком тест теперь ждёт полного декодирования видимых картинок, плюс один повтор (`retries: 1`) и допуск до 100 отличающихся пикселей на снимок — шум GPU на картинках; настоящие изменения, которые тесты ловили, — от сотен пикселей (слово) до десятков тысяч (цвет).
